# Security

If you find a security problem in Operandi (for example a crafted scene,
image or `.lxo` file that runs code or crashes the app in an exploitable
way, or a problem in the MCP bridge), please don't open a public issue.

Report it privately with GitHub's **Report a vulnerability** button on the
repository's Security tab. While the repository is private that button may
not be there; contact Jason ([manfriday](https://github.com/manfriday))
directly instead. Include the version or commit, your system, and
the steps or file that shows the problem. You'll get an answer within a
week, and credit in the fix unless you'd rather not.

Operandi is pre-release software; fixes go into `main` and the next build.
