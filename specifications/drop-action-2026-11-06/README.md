# Drop Action: hand-off (2026-11-06)

Behaviour-only spec for the top-bar **Drop Action** dropdown. Clean-room: no
reference-app images, names of its internals, or code. Built from public
documentation plus scripted measurements of the reference app's hierarchy and
transform commands (no reverse engineering).

Files:
- `BEHAVIOR-DROP-ACTION.md`: what the control is and what each of the 11
  options does to the dragged item and the target.
- `STAGING.md`: what Operandi needs first, and which options are cheap now.
- `QUESTIONS.md`: open points, each with the pick the build should use until
  Jason says otherwise.

IDs: DA-1.. (behaviour), DA-Q1.. (questions), DA-T1.. (test cases).
