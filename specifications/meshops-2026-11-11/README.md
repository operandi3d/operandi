# MeshOps spec bundle v1 (2026-11-11)

Non-destructive procedural mesh stack for Operandi. Behaviour only, written
in our own words from public documentation and public release notes.

- `BEHAVIOR-MESHOPS.md` — what the user sees and does (MO-nn).
- `SAFETY.md` — shared crash-safety rules (SAFE-nn), with the evidence. Also
  used by the MeshFusion spec. Wins over the behaviour spec.
- `OPERANDI-ARCHITECTURE.md` — what our code has and needs.
- `SCOPE.md` — staged build order and rough size.
- `QUESTIONS.md` — open choices, each with a recommended default.

Not covered here: MeshFusion itself and Boolean options (separate specs).
