# Defaults (after Reset)

**EBC-D-01 Edge Bevel:** Mode Inset, Inset 0, Use Material off, Round Level
0, Sharp off, Shape Round, Mitering 0, Coplanar off, Depth 1 (100%),
Boundary Extend on. Mode values: Inset, Width. Shape values: Round, Square,
Sharp.

**EBC-D-02 Edge Chamfer:** Offset 0, Mode Inset, Segments 1, Shape Round,
Stop At Edge on, Auto Weld off, Use Material off (name "Default"), Depth 1,
Parallel on, Coplanar off, Edge End Profile, Flatness 0.00001, Reverse X/Y
off, Boundary Extend on, Mitering 0, Sharp Corner off, Boundary Coplanar on.
Edge End values: Profile, Triangle Fan.
