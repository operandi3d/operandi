# Handle tooltips (MN-09): GUI checklist (2026-11-19)

For Jason or Codex, on the QA build. Hover each handle and wait for the
tooltip; start a drag and check it goes away (UIC-05).

1. Bevel / Smooth Shift: the blue arrow says Shift, the red one Inset.
2. Twist Bevel: Shift arrow, Inset square, Twist ring, Bend arrow, Bend
   Direction ring each say what a drag changes.
3. Edge Extend: arrows (move), rings (turn, Ctrl snaps), squares (scale,
   Ctrl equal).
4. Move with a Linear falloff: Start, End and their X/Y/Z arrows; Radial
   and Cylinder: centre, size and axis arrows.
5. Tweak: hovering a point/edge/polygon explains drag and right-drag.
6. A tool with Click to Start armed: hovering the view says to click.
7. Select a spot light / area light / camera: cone, edge, width, height,
   focus and radius handles.
