# Libraries shipped with the Cycles renderer and USD

These C and C++ libraries come from the Blender project's precompiled
library pack (`scripts/build-cycles.sh` downloads it) and are copied into
the app's `Contents/Frameworks/` folder, or built into one of those
libraries, when Operandi is built with Cycles or USD (`scripts/build-usd.sh`). Each folder holds that
project's licence text exactly as published at the version shown.
See `docs/DEPENDENCIES.md` for the full table.
