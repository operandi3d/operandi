# Selection action centre in Edge/Vertex mode: GUI check

1. New scene, add a cube. Edge mode, select one top edge.
2. Action Center menu: Selection is not greyed. Pick it.
3. Rotate (E): the handle sits at the edge's middle, tilted 45° between the
   top and the side it borders.
4. Vertex mode, select the four top points: Selection still available; the
   handle sits at the top's centre, upright.
5. Edge mode with nothing selected: Selection is available; the handle is at
   the cube's centre with World axes.
6. Move the cube (Item mode), back to Edge mode with an edge selected:
   Selection is still not greyed.
