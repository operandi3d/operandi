# Link buttons follow-up (MN-06b): GUI checklist (2026-11-20)

For Jason or Codex, on the QA build.

1. Item mode, a box selected. Item Transform's Position X row has a chain
   icon just left of its arrows, as tall as them; Y and Z have none but
   their fields are as wide as X's. Clicking cycles a broken chain (off),
   two equal links (same value), a big and a small link (scale together),
   links with a cyan plus (add together).
2. Hover the button: "Link: off (...)", then "Click: link same value",
   then the Enter keys (Cmd+Alt+Enter, Cmd+Enter, Alt+Enter on a Mac).
3. Move a polygon (W). Tool Properties' Position (offset) X row has the
   same button. Set it to same value, type 2 in X, Enter: X, Y and Z are
   all 2 m and the polygon moves diagonally.
4. With the button off: Alt+Enter on Y adds the same change to all three,
   Cmd+Enter scales them, Cmd+Alt+Enter copies. The button stays off.
5. Box tool: Segments X/Y/Z, scale together (Cmd+Enter) with 2/3/5 and
   X typed as 3: 3, 5, 8 (rounded).
6. With a tool live, Item Transform is greyed and its chain icon fades
   with it.
