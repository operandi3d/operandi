# Maximise any panel (MN-08): GUI checklist (2026-11-19)

For Jason or Codex, on the QA build. Checked first: before this branch
the keys worked over 3D views only.

1. Pointer over the Items list, Numpad 0 (or Alt+0): Items fills the right
   column; again: Properties comes back at the same size.
2. Same over Properties, over the Shader Tree / Groups tab (its whole tab
   group fills), and over Tool Properties (it fills the left column).
3. Click into a text field (Item name), pointer over Items, Alt+0: the key
   types; nothing maximises.
4. Pointer over a 3D view: the view's Maximise, as before.
5. In a docked layout (after moving a panel with its grip), the same:
   the panel fills the split it sits in, the rest of the window stays.
