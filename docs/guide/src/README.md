# Welcome

This guide shows you how to use Operandi: what each part of the window is
for, and how each tool works.

- New to Operandi? Start with [Getting started](getting-started.md).
- Looking for a part of the window? See [Interface](interface/window.md).
- Looking for a tool? Use the list on the left, or search with the
  magnifying glass at the top (or press **S**).

Pages in grey in the list aren't written yet.

## About this guide

The guide describes the version of Operandi it was built with, 0.1.0.
Every picture in it is a capture of Operandi itself, made by a script so it
can be remade for each release.
