# Keyboard shortcuts

These are the keys Operandi starts with. You can change any of them in the **Input Map** (**Edit > Input Map…**, or **Input Map…** under **Input** in **Edit > Preferences…**); the list there also shows every action without a key.

- **Ctrl** is the **Cmd** key on a Mac, as everywhere in this guide.
- **Control** is the Control key on every system, a Mac's too.
- **Alt** is the **Option** key on a Mac keyboard.
- Some keys appear on more than one row. They do different things depending on the selection mode, the tool or the window under the pointer: **B** is **Bevel** in Polygon mode, **Edge Bevel** in Edge mode and **Vertex Bevel** in Vertex mode.
